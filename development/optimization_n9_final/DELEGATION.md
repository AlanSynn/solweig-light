# Delegate implementation, not the decision to keep trying forever

Coordinator: the configured Claude Code GLM model. Difficult exactness reviews/implementation: authenticated Opus when available, otherwise independent GLM with honest route labels. This package does not assume names prove actual provider identity and does not request new gateways or credentials. No Astra/Codex callback.

Use three coherent ownership scopes: (1) producer/classification and the equally optimized Numba control; (2) private stream/native ownership integration; (3) evidence plus release-scope audit. The third scope may use a separate read-only release reviewer, and every implementation gets an independent author-distinct review. These are scopes, not a cap on useful inference sessions. Avoid dozens of tiny agents forwarding reports about reports. Do not recursively delegate without a new independent scope.

Task packets include immutable base, owned paths, exact input/ownership contract, allowed tier, CPU/RAM budget, output evidence and terminal condition. Workers receive the relevant dossier, not all historic packets. One integrator owns shared engine/dispatcher/API/packaging files. Worker alternatives use detached worktrees, not a new integration branch. Only one performance owner holds the host lease. No competing build/test/JIT during timing.

Completion event or supported blocking wait replaces polling. Send a result only after implementation plus relevant tests, or a genuine external blocker. Do not ask the user after every intermediate gate. Brief records contain changed files, executed commands, exact results, limitations and requested integration action. Logs are files, not repeated lead-context transcripts.

Permitted ordinary repairs: correctness bugs revealed by small tests, linkage/ABI mistakes, fixture imports, zero-size-harness issue, source-copy drift. Not permitted after a valid performance failure: a new framework, GPU port, rewritten goal, new synthetic favorable workload, relaxed threshold, another optimizer generation. The task transitions to CPU-only closure.

Host quiet-window failure is bounded environment handling, not an excuse for 50 lead polls. Observe only the frozen opportunities; record unavailable evidence and close native for this release when needed. Token abundance does not authorize unlimited local execution or CI.
