# Developer experience and release closure

Ordinary user behavior remains identical to current main: same distribution/import, same seven workflows, same CLI and existing companion installation, same signatures/defaults, input folders, outputs, masks and chronology. Core own-met TIFF execution requires no Torch, CUDA, new compiler, framework, provider, env variable, model selection or network call. Preserve existing GDAL prerequisites rather than claiming they disappeared.

Use existing NumPy/Numba/SciPy first. Optional GPU/native modules are lazy, failure-classified and never imported on a supported CPU-only default. Unsupported optimized profile declines before execution. Failures after admitted execution are loud. Expert old backend override behavior is not silently changed by this campaign. No default activation through a registry whose files live only in development/.

Source install/editable/wheel must run from outside the repository, with import origin captured. Test a no-env call and CLI with real small TIFFs, source-checkout absent, read-only site-packages where applicable, clean build directory, no new compiler and no accidental original-upstream import collision. Wheel manifests must exclude research copies, tests, captures and disabled backend scaffolding from runtime closure. If native binary is eventually justified, proper platform/ABI tags, supported ISA detection and no first-use downloads/builds are required; compiler-free source fallback remains functional.

A resource-tuned profile is not unchanged-default DX proof. If optimization wins only with a new flag, report opt-in improvement, not default success. Preserve public runtime controls; internal choices must remain within the caller's actual grant.

Final report contains exact active route, eligible coverage, numerical evidence, per-cell raw times, resource scope, cold behavior, installed tests, optional unavailable gates, rejected variants and final SHA. Research termination is not goal attainment. Main merge is not automatic. A retained-main result is a valid closure when no material exact gain is demonstrated.
