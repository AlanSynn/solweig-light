# Required coverage dimensions

This matrix is a test-design guide, not an instruction for the full Cartesian product. Use pairwise/boundary-selected fixtures and cover every changed contract. Most cases belong to L0/L1, not full-size runs.

| Axis | Required selected cases | Main purpose |
|---|---|---|
| Temperature representation | Python scalar, NumPy scalar, ndarray 0d, (1,), (1,1), true field | distinguish numeric value from promotion profile |
| Precision | f32/f64 air, independent sun/shade types, mixed masks | preserve actual intermediate graph |
| Material | no landcover, standard class-99 singleton, malformed/multiple wall rows, supported direct field API | prove ordinary daytime coverage and fallback |
| Time | day/night transitions, 24/48 steps, firstdaytime, multi-day, restart | retain chronology and state |
| Geometry | dense, sparse/open, canopy/trunk gap, positive bush, negative elevations, shallow sun | preserve discrete geometry |
| Visibility | binary, ternary incl 2, raw, mixed, reserved/corrupt code | no Boolean truncation or hidden fast-path exclusions |
| Layout | lane tails, block 128/1024, nonmultiple final block, strides/alignment | preserve output and ownership |
| Aliases | input-output overlap, Tg/material/ewall aliases, repeated scratch | no unsafe hoisting or reuse |
| Math edges | signed zero, safe extremes, overflow-producing finite inputs, NaN/Inf, np.seterr modes | admission/warning correctness |
| Outputs | main defaults, selected all outputs, WBGT, full diagnostics | no hidden work/semantics reduction |
| Storage | absent/warm/corrupt cache, source changes, signed-zero stored tiles, checkpoint interruptions | exact integrity and recovery |
| Parallelism | explicit serial, actual masks 1/2/4, independent tile processes, writer lag | true budget and race-free execution |
| Installation | wheel outside repo, source fallback, read-only package, no-env CLI/API, optional deps absent | unchanged DX and real route |
| Hardware | actual tested CPU/OS/math profile; GPU only if available/capable | no extrapolated platform qualification |

Capture intermediate coefficients and prefix states for the new typed numerical path. Capture full per-timestep state and live radiation for L2. Large L4 may use finalized hashes plus selected traces only as allowed by the frozen protocol, but cannot substitute two scenes for the actual target corpus.

Beware inherited tests with side effects: historical installed conftest may write evidence at session end. Run such tests in a controlled copy/worktree or preserve and restore ONLY files known to have been generated by that test after verifying hashes. Never broadly checkout/reset user changes. Known baseline failures and scientific deviations remain recorded with source-specific provenance.
