# Fixed decisions and delegated authority

This packet is the high-level design. The coordinator implements it within Claude Code; it does not summon Astra/Codex for ordinary design review. Source/protocol discrepancies are evidence to refine the implementation, not permission to change the scientific contract.

## Fixed

1. Continue only on `perf/cpu-optimization`. No reset to a checkpoint; one integrator writes that branch. Detached worker worktrees are allowed at explicit immutable commits.
2. Preserve all seven public workflows, Python defaults/signatures, CLI, TIFF/ZIP/NPZ, explicit `solweig_gpu` compatibility distribution, and import-collision handling. No Torch/CUDA requirement in the own-met core.
3. Preserve original resolution, true logical tile extent/context, patch set/order, timesteps, vegetation, ray samples/approved certificates, and all demanded radiation/state. Internal blocks never redefine physical tiles.
4. New backends are **optional CPU islands**. Default remains accepted Numba until an explicit measured promotion; installation alone never auto-selects a backend. Keep core install and import free of optional runtime initialization.
5. Start with the actual accepted longwave primary reducer. Keep accepted decoder, original SLEEF/math preparation and boundary casting outside it. Both patch sweeps, the reflection dependency and the current seven-output kernel contract remain.
6. Freeze the typed expression graph from actual baseline specializations, not the displayed Python expression alone. float32 output does not imply every intermediate is float32. No new FMA, reassociation, reciprocal approximation, mask algebra, or transcendental implementation without exact admission.
7. Three controls are required: A accepted Numba, B same new layout/schedule in Numba, C matching foreign backend. A-to-B is algorithm/layout gain; B-to-C is backend-specific gain; deployment decision uses total end-to-end A/B/C costs.
8. Accepted v6 changes stay. Existing slow fused-radiation and prepared-decoder routes remain OFF unless a genuinely new, separately reviewed experiment establishes value.
9. Numerical failure on an admitted domain is a failed backend experiment. It is not silently swallowed or hidden by fallback. Known unsupported inputs fall back **before execution and side effects**, with logged reasons and truthful coverage counts.
10. Strict resource envelopes include every library's native pool, mapped pages, compiler cache, conversion buffers and pending async work. OS logical core count is not a measurement of equivalent performance cores.
11. Tile state stays chronological and in isolated worker processes. A native kernel may use pixel threads; concurrent Python tile calls in one process are not authorized by this backend task. Current module-global demand/runtime state needs separate isolation proof before such a redesign.
12. Keep artifact verification, content identities, flush/fsync and checkpoint frequency. Do not claim bridge/no-copy/zero-memory costs without measuring actual allocations and synchronization.
13. Development is small and incremental; full 1024² x 24 spatial tiles only on final selected source. No automatic full framework/platform/CI matrix.
14. Baseline and original references are immutable and isolated. Synthetic arithmetic tests do not become reference goldens. Inherited failures remain failed/dispositioned with exact scope.
15. One target run is one observation, not p95/reliability or full P7/P8 release qualification. Framework research completion and actual 24-tile target completion are separate statuses.
16. No artificial inference-token or total-agent cap. Only useful, dependency-ready work is delegated. Actual host resource and tool limits still bind. No manager busy polling.
17. Real Opus must be verified through the existing authenticated route. A GLM-mapped `opus` alias is not Anthropic Opus. Unknown route stays unknown; use independent GLM reviewers where necessary.
18. No automatic push/PR/main merge, hosted CI expansion, privileged package installation, credentials change, cloud spend or remote benchmark infrastructure.

## Delegated without intermediate approval

Workers may choose microtile layouts, helpers, bindings, explicit scalar specialization, bounded compilation, cache namespaces, private experimental source paths and small test fixtures. They may reject a backend, narrow a proven guard with representative coverage measurements, or improve B instead of adding C. Independent reviewers may repair a proof and request focused counterexamples. The integrator may resolve interface details and land reviewed small commits on the same branch.

A source-size change does not justify rewriting the complete model. New test budgets, hardware envelopes and performance selection rules are frozen before selecting measured variants. If a necessary component cannot be installed without privileged/global changes, record that backend unavailable and continue another track. Do not build an authentication gateway or a universal numerical compiler as a side project.

## Resolution of inherited instructions

This packet replaces older operational instructions to create renamed branches, call Astra at milestones, run all framework candidates, or benchmark 1024 after every change. It does not override scientific/API/tolerance/security requirements. Preserve useful existing v6 evidence and slim CI; audit only changed dependency closures.
