# Dependency-ordered execution plan

## Wave 0: restore trustworthy baselines without repeating P0

N8-00 records actual branch/HEAD and protected dirty files, accepted source closures, applicable instructions and real model routes. N8-01 snapshots main DX and current defaults. N8-02 instruments real worker entries and timings. N8-03 freezes small workload/protocol/promotion gates. N8-04 checks actual typed LW graph and ownership. These tasks can be divided among independent readers; no numerical source rewrite before the relevant contract is frozen.

Append corrections rather than rewriting B7 evidence. Preserve A0 negative/positive reports. Use the existing original artifacts and branch captures when their dependency identities match. A memory test rejected before spawn is not an arithmetic failure, but remains a test failure until a fair reproducible envelope is fixed and rerun.

## Wave 1: independent low-risk preparation and deployment

- N8-10: one-time native artifact/handle initialization; no arithmetic change.
- N8-11: direct AoSoA producer with exact raw handling and leases.
- N8-20: build/distribution design and local build recipe; no default enable.
- N8-23: installed main-style API/CLI and source-fallback test harness.
- N8-30: independent review service for each immutable patch, only on completion.

Workers own isolated helper modules/tests or proposed patches. Shared dispatch is edited only by integrator. No worker is permitted to default-enable the old native implementation because its leaf timing improves.

## Wave 2: dataflow and multicore

N8-12 constructs producer-matched Numba B. N8-13 implements native AoSoA consumer. N8-14 adds coarse region dispatch and one bounded pool, with microblock/scheduling exactness. N8-21 implements installed-artifact resolver/loader using the build contract. N8-22 prepares policy selection with all rows disabled until qualification.

Do not add separate numba/OpenMP/ISPC pools on each task. Scratch, call boundary and errors are part of the common interface from ARCHITECTURE. Review B and C independently, then compare N8-31 using frozen small cells and actual full region.

## Conditional work after residual review

N8-16 four-bit observation-state cache and N8-17 exact classifier/contribution reuse require real residual coverage and positive cost crossover. N8-18 export/validation staging is independent cold-throughput work. N8-19 GPU is optional research behind a cost and capability gate; it cannot replace the CPU-native deliverable. Each unselected task is `not_selected` with reason, not `complete` or `passed`.

Candidates must present their changed mechanism versus earlier rejected fusion/decoder. A repeat of an identical failed design without a causal change is closed rather than benchmarked again.

## Wave 3: choose the smallest portfolio

N8-32 selects A/B/C portfolio by full-region and small installed totals, proofs, memory and deployment cost. If C loses to B, continue the best identified native boundary improvements within the frozen experimental budget; do not declare native victory by retaining B. If all meaningful C paths lose, retain B/A improvements and mark native default objective open.

N8-40 integrates reviewed code and wires the private planner. N8-41 builds the selected local binary wheel and compiler-free source variant. N8-42 verifies original default calls and mixed/fallback correctness, all affected intermediate/state paths and main surface. N8-43 measures the installed no-env default on held-out cells. No force-native variable in the candidate default test. An internal benchmark switch for A/B is permitted only in the control harness.

## Wave 4: qualification, scale and handover

N8-44 records exact eligible native rows only after independent review and gates. N8-50 freezes source, artifact, scope and final run boundary. N8-51 performs one final large scale campaign when input/reference/resource conditions exist, or records unverified status. Use actual 24 tiles if available; otherwise the known synthetic four-tile shape is a scale guard, not a target substitute. N8-60 delivers same-branch reviewed commits, build products, raw evidence, a scoped certificate or rejection, future residual roadmap and no automatic publication.

## Execution checkpoints without manager polling

Each completed task emits one result record with immutable SHA, files, commands, passed/failed/unavailable tests, measurements, observed routes, review pointer and next dependency. The coordinator handles a completion event then dispatches ready work; it does not repeatedly read worker conversations. A review is a correctness gate, not a user approval pause. Safe local fixes and reruns proceed autonomously.

## Stop-loss and completion

No import-only or wrapper-only prototype completes this task. A native region must reach genuine installed pipeline execution. Do not benchmark all frameworks or larger arrays because tokens are unlimited. If measured coverage and maximum attainable speed cannot repay the integration overhead, stop that candidate and document its future flip condition.

Local completion requires either a genuinely qualified transparent native default on explicit scope, or an honest best verified partial outcome. Global 24-tile achievement and broad release readiness are separate and cannot be invented when resources/data are absent.
